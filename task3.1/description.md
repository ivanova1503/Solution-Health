## 1. Описание решения

Мы отказываемся от ненадёжного FTP и прямой синхронной передачи в CRM. Новый процесс работает по **событийной модели (Event-Driven)** с гарантией доставки:

1.  **Приём данных:** Вместо падающего FTP ставим современный **LIS-адаптер**. Он принимает данные от оборудования по надежному API.
2.  **Дедупликация:** Адаптер проверяет уникальный ID анализа. Если файл пришел дважды, второй отбрасывается (решает проблему дублей XML).
3.  **Шина событий:** Адаптер отправляет событие «Анализ готов» в **Kafka** (брокер сообщений).
4.  **Сохранение в CRM:** Событие забирает сервис CRM, обновляет карточку пациента и подтверждает обработку (Ack).
5.  **Уведомление:** Параллельно событие уходит в сервис уведомлений, который отправляет пуш пациенту. Данные в мобильном приложении подтягиваются через API Gateway (из CRM).

**Почему это надежно:** Если CRM или сервис уведомлений временно недоступны, данные не теряются, а ждут в Kafka. При падении LIS-адаптера данные не пропадают, так как адаптер подтверждает получение только после записи в очередь.

## 2. Сравнение архитектурных решений

| Вариант реализации | Гарантии доставки | Задержка (Latency) | Устойчивость к пикам | Сложность эксплуатации | Итог |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. Синхронные REST-вызовы** (LIS → CRM → App) | Низкие (при тайм-ауте данные теряются) | Низкая (зависит от скорости CRM) | Низкая (при пике CRM ляжет) | Низкая | Не подходит |
| **2. FTP + База данных** (как сейчас) | Низкие (файлы теряются, дубли) | Высокая (до 2 часов) | Низкая | Высокая (ручные скрипты) | Не подходит |
| **3. Event-Driven (Kafka) + LIS-адаптер** | **Высокие** (At-least-once, нет потерь) | **Низкая** (секунды) | **Высокая** (буферизация в очереди) | Средняя (стандартный кластер) | **Выбрано** |

**Выбор инструментов:**
*   **Apache Kafka** — выдерживает огромные потоки, хранит данные при сбоях и позволяет нескольким сервисам читать одно событие независимо.
*   **LIS-адаптер (Java)** — служит прослойкой (Anti-Corruption Layer), защищая новые системы от старого формата LIS.
