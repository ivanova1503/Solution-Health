**Цель:** Разработать спецификацию OpenAPI для получения пациентом списка предстоящих записей.

## Пагинация
Выбрана пагинация на основе `limit` и `offset`. В ответе возвращается объект `meta` с общим количеством записей (`total`). Это простой и предсказуемый метод для мобильного клиента. Он позволяет легко реализовать бесконечный скролл. Риск «сдвига» страниц минимален, так как список записей пациента редко обновляется в реальном времени.

## Версионирование
Версия API вынесена в URL (`/api/v1/...`). Это самый прозрачный способ для мобильных приложений. Старые версии клиента, которые ещё не обновились у пациентов, продолжат работать с `v1`, пока разрабатывается `v2`. Это исключает внезапные поломки и позволяет безопасно выпускать новые функции.
